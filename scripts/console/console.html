Run it as a program

Here on claude.ai this page writes commands for you to paste. The same page ships in the repository as a local program: run this once and OmniTask Build Console appears on the Desktop and in the Start menu. Opened from there it runs in its own window, and Start, Stop, Install and the checks become buttons with their output streaming into the page.

PowerShell · once

    

    
No administrator rights. It listens on 127.0.0.1:4310 only, and closes by itself once its window is closed and nothing is running. To open it without the shortcut: yarn console.

Add the Claude key

        Once. Your omnitask-local key goes in a file git never sees.

Start the stack

        The one command. Leave it running.
        
      

      

        It checks the tools, builds the functions, starts the four emulators, waits for them, then
        starts the app. The first run downloads the emulator programs, so give it a couple of minutes.
      

      

        
PowerShell · stays open

        

      

      
Expect OmniTask local stack is up. followed by the two addresses.

    


    

      

        05
        
Open it and sign in

        No real Google account is involved.
        
      

      

        Open http://localhost:4200 and press
        Continue with Google. The popup is the emulator's stand-in: it takes any email and asks for no password.
        Type your OmniFlex admin email there. The security rules treat that one address as the super admin
        (it is written in firestore.rules), locally exactly as in production. Any other address becomes an
        ordinary member, who cannot create projects and sees an empty dashboard. Accounts exist only in the emulator.
      

    


    

      

        06
        
Prove the key works

        One real Claude request.
        
      

      

        It reads the key out of functions/.secret.local, so you never type it, and sends one small
        request through the same code the AI buttons use. It costs a fraction of a cent.
      

      

        
PowerShell · second window

        

      

      
Expect ai-smoke OK: model=claude-opus-5-5. Anything else: paste it into Read an error under Advanced.

    


    

      

        07
        
Stop

        Ctrl+C in the window from step 04.
        
      

      

        Press it once and wait a few seconds. The emulators save your local projects, tasks and accounts into
        .emulator-data/ on the way out, and the next start loads them back.
        Closing the terminal window instead skips the save and can leave the ports held.

Ship it

  

    Production deploys itself. A merge into live starts the
    Deploy to Cloud Run & Firebase workflow, which ships the web app to Cloud Run and deploys
    hosting, Firestore rules and functions. Nothing on this page pushes to live.
  


  


    

      

        S1
        
Merge the pull request

        On GitHub, once it is reviewed.
      

      

        Review and merge #213,
        then watch the run under Actions.
        If the deploy fails, read its log and fix forward with a new pull request.
        Do not push retry commits to live; that ships untested code.
      

    


    

      

        S2
        
Give CI its own key

        Optional. Keeps the production key away from pull-request runs.
      

      

        Create a second key with a low spend limit, then add it at
        Settings, Secrets, Actions
        as a repository secret named exactly this. The PR check uses it when present and falls back to
        ANTHROPIC_API_KEY when not.

What does not run locally

        
    
          
  • Google features: Tasks sync, Contacts, Sheets and Calendar. The emulator's Google token is fake, and Google's own services reject it.
    • 
          
  • GitHub Issues integration: needs the GitHub App secrets.
    • 
          
  • Scheduled functions (scheduledGoogleTasksSync, checkScheduledReminders): not loaded, because the Pub/Sub emulator is not started.
    • 
          
  • Firebase Extensions: image resize, user-data deletion, speech-to-text and the others are production-only.
    • 
          
  • The Flutter mobile app: not wired to the emulators yet.
    •
